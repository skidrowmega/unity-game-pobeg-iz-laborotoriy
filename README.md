# Побег из Лаборатории

3D-рогалик с видом сверху, в котором антропоморфный бобр сбегает из процедурно генерируемой лаборатории, сражаясь с учёными при помощи весла и деревянного пистолета, собирая мусор и обменивая его у лягушки на древесину для крафта и амулеты.

## Основные возможности

- **Процедурная генерация уровней**: каждый забег по этажам лаборатории уникален благодаря системе генерации комнат и коридоров.
- **Боевая система**: используйте весло для ближнего боя и деревянный пистолет для стрельбы по врагам.
- **Противники**: сражайтесь с разными типами учёных — химиками, физиками, математиками и другими.
- **Экономика и крафт**: собирайте мусор, продавайте его лягушке-торговцу и вырезайте из древесины новое оружие.
- **Амулеты**: находите и экипируйте особые амулеты, повышающие характеристики бобра.
- **Побег**: доберитесь до последнего этажа и выберитесь на поверхность, чтобы увидеть сцену победы.

## Установка

###Запуск из исходников (Unity)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/skidrowmega/unity-game-pobeg-iz-laborotoriy.git
   cd unity-game-pobeg-iz-laborotoriy
   ```
2. Откройте **Unity Hub**, нажмите **Add** и выберите папку проекта.
3. Убедитесь, что установлена версия Unity, указанная в `ProjectSettings/ProjectVersion.txt`.
4. Дождитесь импорта ассетов.
5. Откройте стартовую сцену `GameManager.unity`.
6. Нажмите **Play**.
## Использование

После запуска игры (в редакторе или из билда):

- Перемещение персонажа: **WASD** или стрелки.
- Атака веслом: **левая кнопка мыши** .
- Стрельба: **правая кнопка мыши** (при наличии пистолета).
- Взаимодействие с объектами : **E**.
- Парирование: **F**
- Уворот: **SHIFT**
- Инвентарь: **Tab**.
- Использование предмета из инвентаря: Нажатие **ПКМ** по предмету с Зажатым **Tab**
- Пауза: **Esc**.
